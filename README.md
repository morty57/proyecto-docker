# Proyecto Docker - Aplicación Flask + PostgreSQL

Este proyecto implementa una aplicación web en Flask conectada a una base de datos PostgreSQL, utilizando herramientas de DevOps como Docker, Docker Compose y Kubernetes.

---

## 🧱 Tecnologías utilizadas

- Python (Flask)
- PostgreSQL
- Docker
- Docker Compose
- Kubernetes (Minikube)
- Bash (automatización)

---

## 📁 Estructura del proyecto

proyecto-docker/
├── app/                # Aplicación Flask
├── k8s/                # Archivos de Kubernetes
├── scripts/            # Scripts de automatización
├── docker-compose.yml  # Orquestación local
├── .env                # Variables de entorno
├── .gitignore
└── README.md
